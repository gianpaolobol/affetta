# Changelog Affetta 0.4.12

- Selezione automatica e visibile del piatto X1C per materiale.
- Conservazione delle temperature del preset produttore quando valide.
- Supporti `normal(auto)` per ugelli da 0,8 mm.
- Geometria supporti Orca parametrizzata su nozzle e line width.
- Errori geometrici e di quantità restituiti come HTTP 422 JSON.
- Parser tempi G-code corretto per formati umani Prusa/Orca.
- Lettura affidabile di lunghezza e peso filamento dai metadati dello slicer.
- Nuovi campi diagnostici `time_source` e `filament_source`.
- Interfaccia aggiornata per mostrare il piatto applicato.
- Test esaustivo statico di 640 combinazioni Orca e test HTTP quantità.
