# Esecuzione correzione matrice — Affetta 0.4.12

È stato analizzato integralmente il pacchetto `RISULTATI_MATRICE_AFFETTA.zip`. I 288 fallimenti sono stati ricondotti a due cause di profilo Orca, mentre quattro controlli API hanno evidenziato una classificazione HTTP errata. È stata inoltre rilevata un'anomalia comune ai 672 casi superati nel calcolo di tempo e materiale.

La build 0.4.12 corregge tutte le cause identificabili dal report e include test di regressione. La conferma definitiva richiede la ripetizione della matrice sul PC Windows reale.
